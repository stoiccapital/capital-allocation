# Capital Allocation

A single-page allocation sim. One file, no backend. Open `index.html` in a browser.

Teaches by playing: three asset classes, leverage, hurdle rates, market crashes, inflation, dividend tax, holding-company valuation, bankruptcy, consumption. One second = one year.

Pick your LTV, set your hurdle, let auto-deploy run, and watch what emerges over 100+ years of simulated capital allocation.

## Phases

- **Bootstrap (y 0–15)** — leverage, concentrate, 50%+ CAGR, bust risk
- **Scaling (y 15–80)** — hurdle rate earns its keep, 20–30% CAGR
- **Compression (y 80–200)** — caps bite, drift decays, 7–15% CAGR
- **Stewardship (y 200+)** — growth → inflation + yield, pure preservation

## Stack

Pure HTML + CSS + vanilla JS. No build step, no dependencies.
